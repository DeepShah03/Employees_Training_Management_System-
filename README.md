Employee Training Management System (ETMS)

Project Overview
Employee Training Management System (ETMS) is a web-based application developed using ASP.NET Core MVC to automate and manage employee training, assessments, project tracking, and performance evaluation within an organization.

Objectives
• Centralize employee training and assessment management
• Automate test evaluation and performance tracking
• Enable trainers to manage learning materials and projects
• Provide real-time progress monitoring and reporting

Key Features
• Role-based access (Admin, Trainer, Employee)
• Training material management (PDFs, videos)
• Online assessments with auto-evaluation
• Project assignment and submission
• Performance tracking and reports
• Notifications and alerts

Technology Stack
Backend: ASP.NET Core MVC, C#
Frontend: HTML, CSS, Bootstrap, JavaScript, jQuery
Database: SQL Server, Entity Framework Core
Security: ASP.NET Identity

Modules
• User Authentication & Authorization
• Admin Dashboard
• Trainer Dashboard
• Employee Dashboard
• Assessment Management
• Project Management
• Reporting & Analytics

Installation
1. Clone the repository from GitHub
2. Open the project in Visual Studio 2022
3. Configure SQL Server connection
4. Run database migrations
5. Run the application

Future Enhancements
• Cloud deployment
• Mobile application
• Advanced analytics
• Certificate generation
